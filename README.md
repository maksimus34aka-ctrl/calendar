Репозиторий Calendar (Holidays)
Описание
Calendar (Holidays) – это набор консольных утилит на 8 языках программирования для отображения календаря на указанный месяц с выделением выходных и праздничных дней. Программа поддерживает:

Отображение календаря на любой месяц любого года.

Подсветку выходных (суббота и воскресенье) и праздничных дней (государственные праздники).

Настройку страны – список праздников для России (по умолчанию), США или других стран (можно расширить).

Интерактивный режим – если аргументы не заданы, программа запрашивает год и месяц.

Цветной вывод в терминале (ANSI) для удобства восприятия.

Сохранение календаря в текстовый файл (опционально).

Расширяемость – праздники загружаются из встроенного списка или из внешнего JSON-файла.

Установка и запуск
Каждый файл является самостоятельной программой. Для запуска необходима соответствующая среда выполнения.

Язык	Зависимости	Команда запуска
Python	Python 3.8+ (только стандартная библиотека)	python calendar.py [год] [месяц] [страна]
JavaScript	Node.js 14+ (без внешних модулей)	node calendar.js [год] [месяц] [страна]
TypeScript	Node.js + ts-node (без внешних модулей)	ts-node calendar.ts [год] [месяц] [страна]
Go	Go 1.18+ (без внешних зависимостей)	go run calendar.go [год] [месяц] [страна]
Java	JDK 11+ (без внешних библиотек)	javac Calendar.java && java Calendar [год] [месяц] [страна]
C#	.NET SDK 6.0+ (или csc)	csc Calendar.cs && Calendar.exe [год] [месяц] [страна]
PHP	PHP 8.0+ (без расширений)	php calendar.php [год] [месяц] [страна]
Ruby	Ruby 2.7+ (без гемов)	ruby calendar.rb [год] [месяц] [страна]
Использование
text
calendar [год] [месяц] [страна]
год – четырёхзначное число (по умолчанию текущий год).

месяц – число от 1 до 12 (по умолчанию текущий месяц).

страна – код страны: ru (Россия), us (США), by (Беларусь) и т.д. (по умолчанию ru).

Если аргументы не указаны, программа переходит в интерактивный режим.

Примеры
bash
# Показать календарь на текущий месяц (Россия)
python calendar.py

# Показать календарь на декабрь 2024 года (Россия)
python calendar.py 2024 12

# Показать календарь на январь 2025 года (США)
python calendar.py 2025 1 us
Список праздников (встроенный)
Для России:

1 января – Новый год

7 января – Рождество Христово

23 февраля – День защитника Отечества

8 марта – Международный женский день

1 мая – Праздник Весны и Труда

9 мая – День Победы

12 июня – День России

4 ноября – День народного единства

Для США:

1 января – New Year's Day

15 января – Martin Luther King Jr. Day (третий понедельник января, но для простоты фиксированная дата)

20 февраля – Presidents' Day (третий понедельник февраля, упрощённо)

31 мая – Memorial Day (последний понедельник мая, упрощённо)

4 июля – Independence Day

5 сентября – Labor Day (первый понедельник сентября, упрощённо)

11 ноября – Veterans Day

25 декабря – Christmas Day

Для простоты в примерах мы используем только фиксированные даты.

Особенности реализаций
Все версии используют только стандартные библиотеки языка.

Цветной вывод реализован через ANSI-коды.

Праздники хранятся в виде словаря/массива внутри кода.

Поддержка интерактивного режима (запрос данных, если аргументы не заданы).

Обработка ошибок (неверный месяц, год).
